Users can upload handwritten or printed images, extract text instantly, edit the output, and download the results without installing any software. The application works completely online and is accessible from any device with a web browser.


# Project Overview

The Handwriting to Digital Text App is an OCR-based application designed to convert handwritten or printed text from images into editable digital text. The system uses OCR technology to analyze uploaded images and extract text with high accuracy. It supports multiple languages, including English and Urdu, and provides users with options to edit, copy, and download the extracted text in different formats.

The application runs directly in the browser without requiring an API key, making it fast, accessible, and easy to use. It is useful for students, researchers, professionals, and anyone who wants to digitize handwritten notes efficiently.
